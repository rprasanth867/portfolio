# DNS (Domain Naming System)

The Domain Name System (DNS) is the "phonebook of the internet," translating human-readable domain names (e.g., google.com) into numeric IP addresses (e.g.,) to locate resources.  
It is a hierarchical, distributed system that maps names to IP addresses, enhances security via validation, and improves load speeds through caching.

### DNS Working Diagram (Step-by-Step)

```
User (Browser)
      │
      ▼
DNS Resolver (Recursive Resolver)
      │
      ▼
Root Name Server
      │
      ▼
TLD Name Server (.com, .org, .in)
      │
      ▼
Authoritative Name Server
      │
      ▼
IP Address (e.g., 142.250.xxx.xxx)
      │
      ▼
Website Loads in Browser

```
